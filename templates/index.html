Czym jest Modbus?

Modbus to prosty protokół komunikacyjny używany w automatyce i energetyce. Urządzenie (np. licznik energii) udostępnia tablicę rejestrów 16-bitowych — każdy rejestr to komórka pamięci z numerem (adresem). Odpytujesz urządzenie: "daj mi rejestry od 0 do 10" i dostajesz surowe liczby. Bez nazw, bez typów — musisz wiedzieć (lub wydedukować) co jest pod jakim adresem.

Skaner rejestrów — jak czytać wyniki

Skaner odpytuje zakres adresów i dekoduje każdą parę rejestrów (2 × 16-bit = float32) w trzech wariantach kolejności bajtów. Kolorowe znaczniki oznaczają automatycznie rozpoznane wartości:

  • Napięcie — wartość w zakresie 200–260 (typowe 230V)
  • Prąd — wartość 0.01–100 A
  • Moc — wartość 100–50000 W
  • Częstotliwość — wartość 49–51.5 Hz
  • cos φ — wartość 0.5–1.0
  • Energia — wartość > 100 (kWh)

Wyszarzone wiersze to rejestry z wartościami które nie pasują do znanych wzorców — mogą być puste, nieużywane, lub zawierać dane w innym formacie (int16, uint32).

Tryb Live w skanerze

Po pierwszym skanie kliknij Live — skaner będzie automatycznie odpytywał rejestry co sekundę. Pozwala to obserwować zmiany wartości w czasie rzeczywistym — np. włącz czajnik i patrz który rejestr skoczył o ~2000W. Przydatne do identyfikacji nieznanych rejestrów.

Presety

Preset to plik JSON opisujący mapę rejestrów konkretnego modelu licznika. Zawiera adres każdego rejestru, jego nazwę, jednostkę i grupę. Raz stworzony preset działa dla każdego egzemplarza tego samego modelu — zmieniasz tylko Unit ID.

Presety można tworzyć ręcznie (edytor JSON) lub automatycznie ze skanera (przycisk "Zapisz preset").

Dashboard — tryb wykresów

Przełącznik Karty / Wykresy zmienia widok. Tryb wykresów pokazuje wykresy liniowe z historią ostatnich 60 odczytów (1 minuty) dla każdej grupy parametrów. Wartości liczbowe wyświetlane są jednocześnie obok wykresów.

Przykłady:

# Desktop z symulatorem (domyślne):
python app.py

# RPi + Waveshare RS485/CAN HAT:
python app.py --serial /dev/ttyS0 --baudrate 9600

# RPi + licznik z parity Even:
python app.py --serial /dev/ttyS0 --baudrate 9600 --parity E

python app.py --serial COM3 --baudrate 9600

# Połączenie z bramką Modbus TCP (bez symulatora):
python app.py --no-sim

# Dashboard na innym porcie:
python app.py --port 8080

Jak znaleźć parametry nieznanego licznika

  • Sprawdź naklejkę na obudowie licznika — często podaje adres, baudrate i parity
  • Sprawdź instrukcję producenta (PDF) — szukaj "Modbus Register Map" lub "Communication Parameters"
  • Jeśli nie masz instrukcji, zacznij od: baudrate 9600, parity N, adres 1
  • Jeśli skaner zwraca same zera — spróbuj baudrate 2400 (Eastron) lub parity E (Orno)
  • Jeśli wartości wyglądają bezsensownie (np. 1.7e-38 zamiast 230) — zmień byte order na word_swap
  • Użyj trybu Live w skanerze — włącz/wyłącz obciążenie i patrz które rejestry reagują
  • Nie każdy rejestr to float32 — niektóre mogą być uint16 lub uint32 (energia, status). Te będą wyglądać dziwnie w dekodowaniu float

Fizyczne podłączenie RS-485

Magistrala RS-485 to dwa przewody (A i B) plus opcjonalnie GND. Podłączenie:

  • Waveshare RS485/CAN HAT — wkładasz na piny GPIO Raspberry Pi. Zaciski śrubowe: A↔A, B↔B z licznika
  • GND — podłącz jeśli odległość > 5m lub masz problemy z komunikacją
  • Terminacja — rezystor 120Ω między A i B na końcach magistrali. Waveshare HAT ma wbudowany (jumper). Przy jednym liczniku na krótkim kablu zwykle nie potrzeba
  • Polaryzacja — A to D+, B to D-. Jeśli podłączyłeś i skaner nie odpowiada, zamień A z B
  • Maksymalna długość magistrali RS-485: do 1200m przy 9600 baud
  • Maksymalna liczba urządzeń na jednej magistrali: 32 (standard) lub 256 (z repeaterem)
